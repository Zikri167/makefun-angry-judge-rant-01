# Angry Judge: The Short Rant Contest

A make.fun entry for the "Angry Judge: The Short Rant Contest" bounty. A small Node 22 program (standard library only, deterministic, offline) writes exactly one short, funny rant about an everyday annoyance — autocorrect renaming a client in an already-sent email — to `entry.txt`, validating it first (1–400 characters counted per code point, exactly one line, no control characters, no double spaces, no trailing newline) and verifying the bytes on disk with a read-back check.
